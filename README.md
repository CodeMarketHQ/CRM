# CRM Dashboard

Premium, browser-only Excel-to-CRM analytics dashboard built with HTML5, CSS3 and Vanilla JavaScript.

## Run
Open `index.html` directly, or serve the folder from any static web server / GitHub Pages.

The application uses SheetJS and Apache ECharts from a CDN. Uploaded data is processed entirely in the browser and is not transmitted by the application.

## Core capabilities
- XLSX / XLS upload with worksheet detection and header inference
- Dynamic data profiling and Arabic/English semantic field matching
- Cascading multi-select filters calculated with all active filters except the filter itself
- Date presets and custom ranges
- Dynamic KPI selection, opportunity analytics, representative/customer/location insights
- Interactive ECharts filtering
- Deterministic data highlights
- Data quality profiling and duplicate-row detection
- Searchable/sortable/paginated Data Explorer with column selector
- CSV export of filtered and visible data
- Safe URL / email / phone actions and record detail drawer
- Responsive mobile-first shell and X Academy attribution
